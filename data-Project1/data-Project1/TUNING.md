# 核心算法调参（Hyperparameter Tuning）指南

大家好！

仅仅运行模型的默认设置是不够的，一名优秀的数据科学家需要理解模型背后的“旋钮”——即超参数 (Hyperparameters)。调整这些参数可以极大地影响模型的性能。

下面，我们针对实验中涉及的几个核心模型，介绍一些最重要的超参数、它们的含义以及调整建议。

## 支持向量机 (SVM - SVC)

SVM 是一个功能强大的模型，其性能高度依赖于参数选择。对于文本分类任务，我们通常从线性核开始。

1. C (正则化参数)

含义: 这是最重要的参数之一。它控制了模型的“惩罚”力度。可以理解为模型对“犯错”的容忍度。

C 值较小: 对“犯错”的容忍度高。模型会倾向于选择一个更宽、更简单的决策边界（超平面），即使这意味着会错分一些训练样本。这有助于防止过拟合，增强模型的泛化能力。

C 值较大: 对“犯错”的容忍度低。模型会尽力将所有训练样本都正确分类，这可能导致决策边界变得非常复杂和扭曲，容易导致过拟合。

**调参建议**: C 是一个需要重点调节的参数。可以从 1.0 开始，然后尝试一系列按数量级变化的值，例如 [0.1, 1, 10, 100]。

2. kernel (核函数)

含义: 核函数将数据映射到更高维的空间，以处理线性不可分的问题。

'linear' (线性核): 对于TF-IDF表示的文本数据，这通常是最好、最快的选择。因为文本数据已经是高维且稀疏的，线性核在这种空间中表现得非常好。

'rbf' (径向基函数核): 一种强大的非线性核。当线性核效果不佳时可以尝试，但计算成本更高，且更容易过拟合。使用它时，还需要调节另一个参数 gamma。

**调参建议**: 优先使用 'linear'。在完成了对 C 的调节后，如果想进一步探索，可以尝试 'rbf'。

3. gamma (核系数, 仅用于 'rbf' 等非线性核)

含义: 定义了单个训练样本的影响范围。

gamma 值较小: 影响范围大，决策边界更平滑。

gamma 值较大: 影响范围小，决策边界会紧紧围绕着支持向量，可能导致过拟合。

**调参建议**: 如果使用 'rbf' 核，可以尝试 ['scale', 'auto', 0.1, 1]。

```python
# 示例：创建一个C=10的线性SVM
svm_classifier = SVC(kernel='linear', C=10, random_state=42)
```

## 逻辑回归 (LogisticRegression)

逻辑回归是一个稳定且高效的分类器，同样受正则化参数的控制。

1. C (正则化强度的**倒数**)

含义: 与SVM中的 C 类似，但含义正好相反。它代表正则化强度的倒数。

C 值较小: 更强的正则化。模型参数会被强烈地压缩，模型更简单，有助于防止过拟合。

C 值较大: 更弱的正则化。模型对训练数据的拟合程度会更高，但有过拟合的风险。

**调参建议**: 和SVM类似，可以尝试对数量级 [0.1, 1, 10, 100] 进行搜索。

2. max_iter (最大迭代次数)

含义: 优化算法（求解器）为了找到最佳模型参数所允许的最大迭代次数。

**调参建议**: 默认值通常足够。但如果你在训练时看到 ConvergenceWarning 的警告，说明模型没有在指定次数内收敛，这时你需要增加 max_iter 的值，例如 max_iter=2000。

```python
# 示例：创建一个正则化更强，并增加迭代次数的逻辑回归模型
lr_classifier = LogisticRegression(C=0.1, max_iter=2000, random_state=42)
```


## 多层感知机 (MLPClassifier)

MLP的“黑盒”特性更强，可调参数也更多，主要围绕网络结构和优化过程。

1. hidden_layer_sizes (隐藏层结构)

含义: 定义了神经网络的结构。它是一个元组，每个元素代表一个隐藏层的神经元数量。

(100,): 表示一个拥有100个神经元的隐藏层（这是默认值，也是一个很好的起点）。

(50, 25): 表示两个隐藏层，第一个有50个神经元，第二个有25个。

**调参建议**: 从一个简单的单层网络开始，如 (50,) 或 (100,)。如果性能不佳，可以尝试增加该层的神经元数量，如 (200,)。或者增加网络的深度，如 (100, 50)。注意：更深、更宽的网络意味着更强的学习能力，但训练更慢，也极易过拟合。

2. alpha (L2正则化项)

含义: 与逻辑回归和SVM中的正则化类似，用于惩罚过大的权重，防止模型变得过于复杂。

alpha 值越大: 正则化效果越强。

**调参建议**: 可以尝试 [0.0001, 0.001, 0.01, 0.1]。

3. activation (激活函数)

含义: 为神经元引入非线性，使得网络可以学习复杂的模式。

'relu' (修正线性单元): 默认值，绝大多数情况下的首选。它计算速度快，收敛性好。

'tanh' (双曲正切): 另一个常用选择。

**调参建议**: 保持默认的 'relu' 即可，除非你有特别的理由去更换它。

```python
# 示例：创建一个拥有两个隐藏层，并增强了正则化的MLP
mlp_classifier = MLPClassifier(hidden_layer_sizes=(100, 50), alpha=0.001, max_iter=300, random_state=42)
```

# 如何查看 import 的源文档

我们推荐大家在运行代码的同时，可以去查阅相关包的文档，了解每一个参数的作用，对应理论上算法的流程。在 Python 中，如果你想查看 `import` 的模块或函数对应的文档或源码，有以下几种常见方法：

1. **使用 `help()`**
```python
from sklearn.svm import SVC
help(SVC)
```
会打印出 SVC 的完整类文档，包括参数说明、方法以及用法示例。

2.	查看 __doc__ 属性
```python
print(SVC.__doc__)
```
直接显示 SVC 类的 docstring（相对精简）。

3.	使用 inspect 查看源码
```python
import inspect
print(inspect.getfile(SVC))
```
输出 SVC 源文件路径（一般在 .../sklearn/svm/_classes.py 里），你可以直接打开文件看源码。

4. 在交互环境里用 ? (IPython / Jupyter Notebook)
```python
from sklearn.svm import SVC
SVC?
```
在 Notebook 中会弹出帮助窗口，内容和 help() 类似，还会标明源码位置。

5. 通过谷歌搜索对应文档，如 [SVC 的文档](https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVC.html)
